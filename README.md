
# EurekaVerse 🌌

**Explore the universe of scientific discovery.**

EurekaVerse is an interactive 3D research exploration platform where scientific papers appear as stars in a galaxy. Discover related research, explore connections between publications, and investigate how ideas evolve over time.

## Planned Features

- 🌠 Interactive 3D galaxy of research papers
- 🔗 Connections between related publications
- 🔎 Search and filter by research topic
- 📄 Paper details, abstracts, authors, and publication dates
- ⏳ Timeline for exploring research trends

## Tech Stack

- Frontend: React and Three.js
- Backend: Python and FastAPI
- Research data: OpenAlex API
- Algorithms: Text similarity and research graph exploration

## Project Status

🚧 In development

## Data and Attribution

This project will use publicly accessible academic metadata. Computed similarity between papers will be distinguished from verified citation relationships.
